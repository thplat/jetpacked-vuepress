# Introduction

This is a minimal VuePress 2 site deployed via [Jetpacked.ai](https://jetpacked.ai).

## What is VuePress?

VuePress is a static site generator powered by Vue 3. Perfect for documentation sites, blogs, and landing pages.

## What is Jetpacked?

Jetpacked is a deployment platform that takes your GitHub repo and gives you a live URL automatically. No Dockerfile, no server config, no terminal required.

## How this site was deployed

1. Pushed this repo to GitHub
2. Connected it to Jetpacked
3. Got a live URL in under 10 minutes
