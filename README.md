# Jetpacked VuePress Sample

Minimal VuePress 2 site for testing Jetpacked deployments.

## Stack

- VuePress 2
- Vue 3
- Static output served via nginx

## Running locally

```bash
npm install
npm run dev
```

Visit http://localhost:8080

## Building

```bash
npm run build
```

Output goes to `docs/.vuepress/dist/`
